# FoodFever 🍔🔥
A food delivery web application for Strathmore University students and staff.
*Hot food, fast, anywhere on campus.*

## Features
- Browse campus cafeteria menu
- Add items to cart and see the total
- Choose a delivery location (hostels, lecture halls, library)
- Place an order

## Methodology
Agile (Scrum)

## Tech stack
- HTML, CSS, JavaScript (no backend or database for now)

## How to run
Open `index.html` in a browser, or use the VS Code Live Server extension.
